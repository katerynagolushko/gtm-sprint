GTM Sprint · 12 weeks

A founder curriculum to nail customer acquisition: one weekly goal, one active bet, a Friday number, and a learning decision. Fidelity rises only when evidence allows.

Customer Acquisition Sprint 12 weeks · 1 constraint at a time
Output: repeatable acquisition motion
Month 1 — Clarity & first signal Who buys, where they are, first conversations, first smoke test.
Month 2 — Repeatable reach One motion, volume, message iteration, path to qualified next step.
Month 3 — System & decision Second channel only if earned; economics; freeze the playbook.
01

ICP + where they hang out

Write a listable customer (role, context, pain) and 3 concrete places you can reach them this month. Done = 1-page ICP + channel map.

02

Discovery calls (pain language)

Run problem interviews with a fixed script; capture phrases, current workaround, and “must-have” signals. Done = 10–15 calls logged + insight notes.

03

Offer artifact + CTA

Turn insights into a one-pager or landing promise with one ask (call, waitlist, pilot). Done = live page/doc + clear CTA.

04

First channel smoke test

Run one cheap motion (usually warm intros or community) against a Friday number. Done = bet + results + persevere/pivot/kill.

05

Lock one acquisition motion

Choose the motion with the best Week 4 signal; build list, tools, and weekly ops checklist. Done = chosen motion + 50–100 ICP targets ready.

06

Volume test

Execute meaningful volume in that motion (touches, posts, or light paid) without changing the offer mid-week. Done = activity log + conversion rates.

07

Message / offer iteration

Keep the same channel; change one variable (hook, CTA, ICP slice) and compare to Week 6. Done = A/B learning + winning variant.

08

Qualification → next step

Define what “qualified” means and the path after interest (demo, pilot brief, security questionnaire). Done = funnel stages + Week 8 conversion.

09

Second channel (only if earned)

If Weeks 5–8 produced repeatable signal, add one adjacent channel; otherwise deepen the first. Done = go/no-go on channel #2.

10

CAC / effort economics

Translate weekly work into rough cost per qualified conversation or pilot (time + spend). Done = unit-economics snapshot.

11

Freeze the playbook

Document scripts, tools, list sources, weekly targets, and owner habits that worked. Done = 2–3 page acquisition playbook.

12

Quarter decision

Decide: double down, change ICP, kill a channel, or raise fidelity next quarter. Done = written decision + next 30-day plan.

Weekly operating rule. One active bet only. Each week = assumption → acquisition plan (who / where / how / tools) → Friday metric → learning card. Do not unlock paid scale or a second channel until discovery + a cheap smoke test produced evidence.

Program outcome. Not “12 hypotheses.” A repeatable way to reach a named customer, with numbers you trust and a clear next-quarter bet.
